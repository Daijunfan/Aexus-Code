# Changelog

All notable releases and engineering milestones of **Aexus Code** are documented here.

## [1.1.0] - 2026-11-19

### Security Hardening, Extensible 4-Slot Organizations, Full-Coverage CI & v1.1.0 Release Parity

#### Security, Lineage RBAC & Airgap Enforcement
- **Lineage-Scoped Session RBAC & Live Rank Validation**: `AdeControlHandler` now verifies `_callerSessionId` against live session state (rejecting deleted/archived callers), intersects token rank with live `agent.rank`, enforces `canRankSupervise` + subtree ownership across `session.create`/`role`/`move`/`send`/`stop`/`archive`/`detach`/`delete` (blocking `Employee → Governor` self-promotion and unauthorized root spawning), and requires `engineering.destroy` whenever deleting or archiving a session owning a DAG tree.
- **Slot-Verified `engineering.review` & Identity-Keyed Engine Pools**: Non-human `engineering.review` callers are strictly verified against the active `segment_owner` / `reviewer` slots and bound node session IDs (closing single-agent bypass of `★ Critical` dual sign-off). Long-lived `codex`, `acp`, and `kilo` client pools key by `(cwd, sessionId, rank, pure)` so demoted sessions never reuse higher-privilege processes.
- **Server-Signed Per-Session Capability Tokens (`AEXUS_ADE_SESSION_TOKEN`)**: `AdeControlServer` holds an in-memory 32-byte HMAC secret, mints signed per-session tokens bound to `(sessionId, rank, pure)`, and enforces pure-worker deny tokens (`pure: true`) alongside per-instance `0600` metadata files (`ade-control.<pid>.json`).
- **Scrubbed Subprocess Env (`stripAdeControlEnv`) & Git Hook Neutralization**: Centralized `stripAdeControlEnv()` strips all `AEXUS_ADE_*` control-plane variables before running `verify:` commands, automated `git` worktree ops, OpenSSH commands, and ACP `sqlite3` helpers (now resolved via `PATH` rather than `/usr/bin/sqlite3`). Automated worktree `git commit`/`merge`/`checkout` pass `-c core.hooksPath=/dev/null`.
- **Upfront Pre-Dispatch `verify:` Trust Gate & Revocation UX**: Untrusted `verify:` commands are checked at the start of `runTree()` **before any Worker is dispatched** (saving tokens), with full audit & revocation via **`Aexus ADE: Manage Trusted Verify Commands...`** and `aexus-ade engineering verify-trust list|revoke`. Fixed Windows `verify:` execution to pass `cmd.exe /d /s /c` with `windowsVerbatimArguments: true`.
- **Safe Mode Status Bar Pill, Autonomous DAG Confirmation & Codex Worktree Sandbox**: Added a live Status Bar pill (**`ADE: Safe Mode`** / **`ADE: Autonomous`**) and Command Palette toggle (`Aexus ADE: Toggle Safe / Autonomous Permission Mode`). When `aexus.ade.autonomousMode` is `false`, launching an automated DAG prompts once per project for explicit confirmation and confines Codex Workers to `sandbox: 'workspace-write'` inside their isolated Git worktree (`danger-full-access` requires explicit opt-in).
- **Non-Destructive SSH Config (`syncUserSshDir: false`) & `host.manage` Split**: Defaulted `syncUserSshDir` to `false` so Aexus Code passes `-F <userDataDir>/ssh/effective_ssh_config` strictly to its own SSH sessions/terminals without modifying global `~/.ssh/config`. Split high-privilege **`host.manage`** (`host.upsert`/`delete`/`test`/`import`, `dangerous: true`) out of read-only `host.access`, alongside `engineering.integrate` and `engineering.destroy`.
- **Workspace Prompt-Injection Defense & Role Bridge Opt-Out**: `aexus.ade.organization`, `aexus.ade.engineering.watchdogTimeoutMinutes`, `aexus.ade.autonomousMode`, and `aexus.ade.nativeExtensionRoleBridge.enabled` are `application`-scoped and `restricted: true` (ignoring `.vscode/settings.json` overrides), with transparent role-bridge opt-out via `AEXUS_ADE_DISABLE_NATIVE_ROLE_BRIDGE=1`.

#### Organization & Roles Studio ("Everything is Extensible"), UX Polish & Clean Public Models
- **4-Slot DAG Binding Bar in Role Studio**: Added an interactive **Work-Tree DAG Slot Mapping** bar (`Orchestrator`, `Segment Owner`, `Adversarial Reviewer`, `Pure Executor`) inside `AdeRoleStudioEditorPane` with dirty tracking, save/revert, and live inline validation warnings, alongside **5 starter presets**, `{{variables}}` prompt templates, and the **Rank × Fixed Kernel API Permission Matrix**.
- **Preset-Dynamic Prompts & FinOps + 2-Tier Self-Review Optimization**: DAG review/escalation/watchdog prompts and FinOps tier labels now resolve active preset tier names dynamically (instead of hardcoding `Governor L1`/`Employee L3`), and presets where `segment_owner === reviewer` (`flat-swarm`) automatically skip duplicate secondary self-review.
- **Zero-Warmup Turn-1 Injection & Prompt-Hash Invalidation**: Role charters inject inline on Turn 1, commit only after a successful send, automatically re-inject when Studio edits change the prompt's SHA-256 hash, and recover cleanly after engine auto-compaction.
- **Clean Public Model Catalogs**: Replaced internal/unreleased model aliases in built-in fallback lists and UI placeholders across all 8 engines with publicly shipping upstream model IDs while preserving full dynamic discovery from local CLI configs (`~/.claude/settings.json`, `~/.codex/config.toml`, etc.).
- **Non-Colliding Prompt-to-DAG Shortcut & Visual Craft Fixes**: Moved Prompt-to-DAG to **`Cmd/Ctrl+Shift+K`** (and **`/`** on focused canvas) so VS Code's native `Cmd/Ctrl+K` chords stay intact; renamed the demo button cleanly to **`▶ Simulated Demo (0 tok)`**; fixed Inbox alert kind badges (**`Trust Gate`**, **`Budget Cap`**, **`Circuit Breaker`**, **`Worktree Alert`**, **`Storage Alert`**) and hid empty 0-API pure ranks from Inbox filter pills; fixed sidebar `.ade-worktree-badge` clipping, Role Studio bottom scroll padding, `prefers-reduced-motion`, and High Contrast borders.

#### Deterministic DAG Reliability, Blueprint Sync & CLI Polish
- **Recipe `max_budget_usd` Auto-Enforcement, `org_preset` & 1:1 Blueprint Sync**: Built-in template rendering now emits `max_budget_usd` (and optional `org_preset`), and all 6 files in `examples/blueprints/` are synchronized 1:1 with `ADE_BLUEPRINT_TEMPLATES` (`balanced` preset).
- **Honest `aexus-ssh://` DAG Guard & Realistic Demo Paths**: `initTree` now explicitly guards `aexus-ssh://` URIs with a clear message (interactive ADE sessions, remote editing, Git diffs, and SSH terminals work over `aexus-ssh://`, while DAG Git worktrees require a local Git repository). Updated simulated demo paths to use `aexus-eng/*` branches and `~/.aexus-code/engineering/` paths matching real execution.
- **Pre-Dispatch Budget Admission, Race-Free State & Git-Native Diffs**: Enforced pre-dispatch budget admission + clean `pauseTree` ceiling pauses, race-free async `verify:` node state updates, `git status --porcelain=v2 -z` diffs, dirty-tree merge preflight, `Co-authored-by` trailers, branch-isolated RED circuit breakers, 2-stage zero-token-first Watchdog, and `aexus.ade.pricing` + Subscription `$0` mode.
- **`aexus-ade` CLI `v1.1.0` Parity, Completions & `schemaVersion: 1`**: Completed `bash`/`zsh`/`fish` completions and `--help` with `role`, `engineering generate`, `demo`, and `verify-trust`; added `"schemaVersion": 1` and `aexusVersion` to `doctor --json` / `status`, uniform `--json` support, and CI-ready `doctor` exit codes (`1` fail, `2` `--strict` warn).

#### Version Parity, Open-Source Packaging, Linux Hygiene & Full-Coverage CI
- **Strict `1.1.0` Version Parity**: Added `"aexusVersion": "1.1.0"` to `product.json` and synchronized `extensions/aexus-agents/package.json` (`version: "1.1.0"`, `publisher: "aexus"`) and `ADE_CLI_VERSION = '1.1.0'` in `adeCli.ts`, enforced in CI.
- **Full-Coverage CI (`.github/workflows/aexus-ci.yml`)**: Runs `pnpm run transpile-client`, `node extensions/aexus-agents/esbuild.mts`, `pnpm run typecheck-client`, `tsc -p extensions/aexus-agents/tsconfig.json --noEmit`, `eslint --max-warnings=0` across `src/vs/platform/ade`, `src/vs/workbench/contrib/ade`, **and `extensions/aexus-agents/src`**, ADE platform Node unit tests, **headless Linux (`xvfb-run`) Electron ADE browser workbench unit tests** (`adeControlAndViews`, `adeEngineering`, `adeProjectsService`, `cloudHostsBrowser`), cross-platform `aexus-agents` & CLI tests (`ubuntu`/`macos`/`windows`), and a **Version Parity + Open VSX + Linux Desktop + Blueprint & Link Integrity** job.
- **Clean Linux Packaging & Original Branding**: Switched `product.json` to [Open VSX](https://open-vsx.org/), replaced upstream VS Code branding in `resources/linux/code.desktop` (`Keywords=aexus;ide;ade;agents;editor;`), updated `.github/workflows/release.yml` so Linux archives extract cleanly to `Aexus-Code-linux-x64/`, updated `scripts/aexus-env.ps1` with `.nvmrc` validation & Windows Named Pipe hygiene, and consolidated architecture documentation into [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) with native Mermaid diagrams and adaptive dark/light media.

## [1.0.0] - 2026-11-18

### Initial Public Foundation

#### Organizational ADE & Visual Engineering / Research DAG Studio
- **Armored Nested Dual-Shell Task Pods (`268×172`)**: Outer supervisory review shell physically enclosing a recessed inner pure-execution core inside auto-partitioned Maximal Non-Branching Path (`MNP`) segment lanes.
- **6 Built-In Blueprint Recipes & `.md` Gallery**: `feature-ship`, `bug-hunt-fix`, `security-audit-swarm`, `safe-migration`, `deep-research-lab`, and `arch-teardown` with mini-SVG topology previews and 3 engine presets (`Balanced`, `Max Quality`, `Fast · $2 Cap`).
- **Multi-Tier Agent FinOps**: Real-time estimated USD spend, prompt-cache savings (`Cache Saved $`), per-tier/per-lane/per-node telemetry, and `max_budget_usd` ceilings.
- **Git Worktree Sandbox & Merge Workbench**: Per-segment Git worktree branches (`aexus-eng/*`) with in-studio merge/cleanup controls.
- **Execution Gantt, Vector SVG & PR Audit Report**: Wall-clock execution Gantt strip, vector SVG export, and 1-click Markdown PR Verification Report (`Copy PR Report` / `aexus-ade engineering report`).
- **Prompt-to-DAG & Simulated 0-Token Interactive Demo**: Fast deterministic keyword-to-DAG scaffolding (`<50ms`, migrated to `Cmd/Ctrl+Shift+K` / `/` in `v1.1.0`) plus a simulated `$0.00`-spend interactive demo (`aexus-ade engineering demo`) and `Alt+Cmd/Ctrl+A` `ADE ⇄ IDE` toggle.

#### 8 Native Coding Agent Engines, Control Plane CLI & SSH Cloud Hosts
- Unified local adapters for **Claude Code**, **Codex**, **Google Antigravity**, **Kilo Code**, **OpenCode**, **DeepSeek Harness**, **Cline**, and **Pi**.
- Added `aexus-ade` local control plane CLI (`doctor`, `completion`, `status`, `mode`, `view`, `project`, `host`, `engine`, `session`, `secretary`, `engineering`, `inbox`).
- **Zero-Server SSH Cloud Hosts (`aexus-ssh://`)**: Local + remote multi-OS workspaces over system OpenSSH with VS Code `~/.ssh/config` migration, live two-step remote path browser, remote Git diffs, and hybrid SSH PTY terminals.
- **Cross-Platform Source Builds**: Support for **macOS (`arm64`/`x64`)**, **Windows 10/11 (`x64`/`arm64`)**, and **Linux (`x64`/`arm64`)** across Dark Modern, Light Modern, and High Contrast themes.
