# Changelog

All notable releases and architectural milestones of **Aexus Code** are documented here.

## [1.0.0] - 2026-11-19

### Flagship Commercial-Grade Release

#### 4-Tier Organizational ADE & Visual Engineering / Research DAG Studio
- **Armored Nested Dual-Shell Task Pods (`268×172`)**: Every task pod visibly encloses the recessed inner **`WORKER · L4`** execution core inside the outer **`EMPLOYEE · L3`** adversarial acceptance-review shell, framed inside auto-partitioned **`MGR · L2`** Maximal Non-Branching Path (`MNP`) segment lanes.
- **6 Built-In Blueprint Recipes & Shareable `.aexus-blueprint.md` Gallery**: One-click Engineering & Research DAG templates (`feature-ship`, `bug-hunt-fix`, `security-audit-swarm`, `safe-migration`, `deep-research-lab`, `arch-teardown`) with live mini-SVG topology previews, 3 engine/thinking presets (`Balanced`, `Max Quality`, `Fast · $2 Cap`), and `.md` export/import.
- **4-Tier Agent FinOps & Hard Budget Circuit Breaker**: Real-time USD spend estimation across all 8 native engines, prompt-cache dollar savings (`Cache Saved $`), per-tier/per-lane/per-node spend breakdown, and optional `max_budget_usd` guardrails that automatically pause execution and raise a critical `ADE Inbox` alert if reached.
- **Git Worktree Sandbox & 1-Click Merge Workbench**: Isolated per-segment Git worktrees (`workspace_isolation: worktree`) with live branch badges on `MGR · L2` segment headers and an in-studio `Worktrees` sheet for one-click `Merge All into Project` and `Clean Up Worktrees`.
- **Visual Execution Gantt, Shareable Vector SVG & 1-Click GitHub PR Audit Report**: Wall-clock execution Gantt strip inside the `Logs` sheet, self-contained dark-obsidian vector SVG DAG export (`Export SVG`), and one-click `Copy PR Report` / `↓ .md` download (plus `aexus-ade engineering report`).
- **Zero-Token Interactive Live Demo & Instant Discoverability**: Try the full 6-node parallel worktree DAG choreography with `$0.00` real API spend and zero file changes via the Quick Start pill, Recipes modal, Command Palette (`Aexus ADE: Try Interactive Engineering DAG Demo (0 Tokens)`), or `aexus-ade engineering demo`; instant `ADE ⇄ IDE` toggle via `Alt+Cmd/Ctrl+A`.
- **Canvas Spotlight Filters, Minimap, Undo/Redo & Auto-De-Overlap**: Status spotlight filtering (`All | Active | Gates | Issues`), interactive `DAG MAP` minimap, full `Cmd/Ctrl+Z` Undo/Redo, hover `+` quick-spawn preview ghosts, and automatic de-overlapping of legacy blueprint coordinates.

#### 8 Native Coding Agent Engines, `aexus-ade doctor` & CLI Ergonomics
- Unified native Chat UI and zero-latency role warmup across **Claude Code**, **Codex**, **Google Antigravity**, **Kilo Code**, **OpenCode**, **DeepSeek Harness**, **Cline**, and **Pi**.
- Added **`aexus-ade doctor`** (with TTY-aware ANSI colors honoring `NO_COLOR`/`FORCE_COLOR`), **`--version` / `-v`**, **`completion <bash|zsh|fish>`**, and **`engineering demo | template | report | worktrees | configure --max-budget-usd`**.
- Added cross-platform GitHub Actions CI (`.github/workflows/aexus-ci.yml` on Linux, macOS, and Windows), `CODE_OF_CONDUCT.md`, cleaned Issue templates & `CODEOWNERS`, and Aexus-owned Help menu URLs.

#### Zero-Server SSH Cloud Hosts, Obsidian Cockpit UI & Cross-Platform Parity
- **Cloud Host Studio (`aexus-ssh://`)**: Zero-server multiplexed OpenSSH workspaces with automatic VS Code & `~/.ssh/config` migration, unified two-step `+` Host → Live Path Auto-Popup Picker (with 0ms Backspace parent navigation and Windows multi-drive browsing), remote Git diffs, and hybrid SSH PTY terminals.
- **Aexus Orbit & Quiet Cards Chat UX**: 1:1 unclipped animated Aexus Code working emblem, natural-flow inline thinking progress with centered glassmorphic `Jump to latest` pill, tactile composer halo, and unified `--aexus-*` Obsidian Cockpit design tokens across Dark Modern, Light Modern, and High Contrast themes.
- **Full Cross-Platform Support**: Native builds and verified packaging/install flows across **macOS (`arm64`/`x64`)**, **Windows 10/11 (`x64`/`arm64`)**, and **Linux (`x64`/`arm64`)**.
