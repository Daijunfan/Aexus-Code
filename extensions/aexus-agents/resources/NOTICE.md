Engine brand icons are used solely to identify each connected local Coding Agent CLI:
- Kilo Code (`kilo-*.svg`): original engine mark from Kilo Code (`Kilo-Org/kilocode`), MIT license.
- OpenCode (`opencode-*.svg`): original geometric mark from OpenCode (`anomalyco/opencode`), MIT license.
- Cline (`cline-*.svg`): original bot emblem from Cline (`cline/cline`), Apache-2.0 license.
- Pi (`pi-*.svg`): original multi-color mark from Pi (`pi.dev`), MIT license.
- DeepSeek (`dsh-*.svg`): DeepSeek whale mark via Simple Icons (`simple-icons/simple-icons`), CC0-1.0 license.
- Claude (`claude-*.svg`), OpenAI Codex (`codex-*.svg`), and Google Antigravity (`antigravity-*.svg`): brand identification marks in their respective official palettes.
